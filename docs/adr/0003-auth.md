# ADR-0003: JWT bearer auth, Argon2id passwords, admin-only MVP

- **Status:** Accepted
- **Date:** 2026-11-19

## Context

Children's and guardians' data is personal data about minors, so the app cannot ship
without authentication. The MVP has a single ministry administrator, but class leaders and
parents are planned.

## Decision

- `users` table from day one with roles `admin`, `leader`, `parent`; only `admin` is
  enabled in the MVP.
- Passwords hashed with Argon2id via `pwdlib`; never logged or returned.
- `POST /v1/auth/login` returns an HS256 JWT (8 h) with `sub`, `role`, `iat`, `exp`.
- Angular keeps the token in memory; no `localStorage`/`sessionStorage` persistence.
- Authorization is enforced server-side on every route and every object access.
- Login attempts are rate-limited; the secret comes from the environment.

## Consequences

- Stateless API, simple horizontal scaling.
- Users re-authenticate after a page reload until refresh tokens land in phase 2.
- Role checks are already modeled, so enabling class-leader access is additive.
- A compromised token is valid until expiry, bounded by the 8 h lifetime and TLS-only
  transport.
